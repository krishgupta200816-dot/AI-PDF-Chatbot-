# ✧ AI-PDF-Chatbot

🚀 **Live App:** [Open AI-PDF-Chatbot](https://imj5yfijxhm6ismkkmhkkx.streamlit.app/)

An AI-powered document assistant that helps users understand and explore PDF documents using Google Gemini, FAISS, and Sentence Transformers.

## Features

- Upload multiple PDF documents.
- Extract and process PDF text.
- Ask questions about uploaded documents.
- Retrieve relevant information using semantic search.
- Generate MCQ quizzes from document content.

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Sentence Transformers
- FAISS
- PyPDF

## Project Status

Currently under development. More features and improvements are coming!

## Run Locally

1. Clone this repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Add your Gemini API key to a `.env` file.
4. Run the application:

```bash
streamlit run app.py
```

**Note:** Never share or upload your API key.
